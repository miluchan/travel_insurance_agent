# AI 旅遊保險智慧管家 V1.2.4｜關注保障＋十檔表格修正版

本版針對兩個測試錯誤修正：

1. 自然語言「比較擔心意外事故、生病、海外緊急救援跟行李遺失」現在正確同步為：
   - 意外傷害
   - 海外醫療
   - 緊急救援
   - 行李損失
   並與前端 checkbox 的 canonical value 完全一致，不再出現「旅行文件損失」等錯誤映射。

2. 十檔比較表重新對齊欄位：
   - 選擇
   - 旅行意外身故／失能
   - 傷害醫療
   - 海外突發疾病醫療
   - 總保費
   每列只有五個對應欄位。原本額外的「100萬檔／200萬檔」文字已移除，避免資料整欄錯位。
   AI 建議只顯示在選擇欄，預設仍勾選 600萬檔。

Demo 保額與保費仍只用於 UX 驗證，並非正式保險公司報價。
